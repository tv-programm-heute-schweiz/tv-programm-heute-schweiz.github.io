# TV Kompass Schweiz

Statischer, deutschsprachiger TV-Ratgeber für die Schweiz. Der öffentliche GitHub-Pages-Auftritt erklärt Sender, hilft bei der Auswahl für den Fernsehabend und verweist transparent auf die aktuelle Programmübersicht von TVProgrammHeute.net.

## Inhalte

- responsive Startseite
- Schweizer Senderguide
- Ratgeber für den Fernsehabend
- FAQ mit strukturierten Daten
- `robots.txt`, `sitemap.xml` und eigene 404-Seite
